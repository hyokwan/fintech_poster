# Creator Studio

AI핀테크융합과 유튜브 채널과 학과 홍보에 쓰는 이미지를 브라우저에서 편집하고 바로 저장하는 도구입니다.

| 탭 | 용도 | 저장 규격 |
| --- | --- | --- |
| 유튜브 썸네일 | 영상 썸네일 (기존 노트 스타일 유지) | 1280×720 PNG (2MB 넘으면 자동 JPG) |
| 학과 포스터 | 교육생 모집 전단지 | 인쇄용 2480×3508 PNG (A4 300dpi) / 웹용 1240×1754 JPG |
| 자유 편집 | 포스터를 미리캔버스처럼 자유롭게 편집 | 학과 포스터와 같음 |
| 엠블럼 | 학과 엠블럼 (정사각형·원형·가로형) | 투명 배경 PNG (기본/2배/512px), 흰 배경 JPG |
| 인스타·페이스북 | 학과 모집 홍보, 유튜브 영상 홍보 게시물 | 1080×1350, 1080×1080, 1080×1920, 1200×630 JPG |

## 실행

Node.js만 있으면 되고, 따로 설치할 패키지는 없습니다.

```bash
node server.js
```

브라우저에서 http://localhost:3001 로 접속합니다.

포트를 바꾸려면 환경변수 `PORT`를 지정합니다.

```powershell
$env:PORT=3005; node server.js
```

## 사용법

### 공통

- 입력한 문구와 설정은 브라우저에 자동으로 저장되어, 다시 열어도 그대로 남아 있습니다.
- **저장하기** 버튼을 누르면 브라우저 다운로드 폴더와 프로젝트의 `output/` 폴더에 동시에 저장됩니다.
- 제목에서 `*별표*`로 감싼 단어는 강조색으로 표시됩니다. (썸네일, SNS)

### 유튜브 썸네일

- **노트** 레이아웃: 기존 채널 썸네일(`baseImage/baseImage.png`) 형태를 유지한 디자인입니다.
  - 색상: 프리미엄(기본), 로열, 블랙골드, 오리지널, 딥블루, 민트, 코랄
  - 옵션: 강조 단어 표현(네이비/형광펜/없음), 글씨 입체 그림자, 배경 반짝이
- **네온** 레이아웃: 다크 테크 스타일입니다. 오른쪽에 GPU 칩 그래픽이나 업로드한 사진을 넣을 수 있습니다.
- 아래쪽 작은 미리보기로 유튜브 목록 크기에서도 글씨가 잘 읽히는지 확인할 수 있습니다.

### 학과 포스터

- `basePoster/` 폴더의 전단지를 화면에 그대로 재현했습니다.
- **포스터 위 글씨를 직접 클릭해서** 수정합니다. Enter는 줄바꿈, Ctrl+Z는 되돌리기입니다.
- 로고는 원본 전단지에서 자동으로 잘라서 씁니다. 다른 로고 파일로 바꿀 수도 있습니다.
- 포인트 색, 배경색, 원형 장식 표시 여부를 바꿀 수 있습니다.
- **원본 문구로 되돌리기** 버튼을 누르면 전단지 원래 내용으로 돌아갑니다.

### 자유 편집

- 원본 전단지 배치에서 시작해서, 모든 글씨·카드·이미지를 **끌어서 옮기고 크기를 바꿀 수** 있습니다.
- 왼쪽 **요소** 탭: 제목·본문·라벨 같은 텍스트, 도형, 포스터 블록(숫자 카드, 프로그램 카드, 일정 카드 등)을 클릭하거나 끌어다 놓아 추가합니다.
- 왼쪽 **이미지** 탭: 이미지를 올리거나, 학과 로고·엠블럼(`baseEmblem/`)을 넣습니다. 이미지 파일을 포스터 위로 바로 끌어다 놓거나 Ctrl+V로 붙여넣어도 됩니다.
- 왼쪽 **레이어** 탭: 겹친 순서를 보고, 요소를 숨기거나 잠급니다.
- 조작
  - 클릭 선택, Shift+클릭 여러 개 선택, 빈 곳을 드래그해서 범위 선택
  - 더블클릭으로 글씨 수정 (Esc로 끝내기). 이미지를 더블클릭하면 다른 이미지로 바꿉니다.
  - 글씨는 모서리를 끌면 글씨 크기가 함께 커지고, 양옆을 끌면 글 상자 폭만 바뀝니다.
  - 옮길 때 페이지 가운데나 다른 요소의 가장자리에 자석처럼 붙습니다. (Alt를 누르면 끔)
  - Ctrl+Z 되돌리기, Ctrl+D 복제, Ctrl+C/V 복사, Delete 삭제, 방향키로 1px(Shift 10px) 이동, Ctrl+휠 확대/축소
- 작업 내용은 서버의 `projects/poster.json`에 자동 저장되어, 다른 브라우저에서 열어도 그대로입니다.
- 오른쪽 **원본 전단지 배치로 되돌리기**를 누르면 처음 상태로 돌아갑니다.
- 이미지 탭의 **심볼 마크 (투명)**은 엠블럼 원본에서 심볼만 투명하게 잘라낸 것이라 어떤 배경 위에도 올릴 수 있습니다.

### 엠블럼

- 자유 편집과 같은 방식으로 편집합니다. 위쪽에서 **정사각형 / 원형 / 가로형** 규격을 고르고, 규격마다 작업이 따로 저장됩니다.
- 심볼 마크는 `baseEmblem/AI핀테크융합과.jpeg`에서 흰 배경을 지우고 자동으로 잘라 씁니다. 글씨는 이미지가 아니라 텍스트라서 더블클릭으로 바로 고칠 수 있습니다.
- 배경을 **투명**(체크무늬)으로 두면 PNG에 투명 배경으로 저장됩니다. 원형은 원 바깥이 항상 투명합니다.
- **브랜드 색**을 바꾸면 브랜드 색을 쓴 글씨가 한꺼번에 바뀝니다. (흰 글씨 엠블럼 등)
- 파일 이름 뒤에 규격(`_정사각형`, `_원형`, `_가로형`)이 붙어 `output/emblem/`에 저장됩니다.

### 인스타·페이스북

- 템플릿
  - **학과 모집 홍보**: 포스터와 같은 디자인에 숫자 카드와 접수 일정을 넣습니다. 숫자 카드는 한 줄에 하나씩 `라벨 | 값` 형식으로 입력합니다.
  - **유튜브 영상 홍보**: **최근 저장한 썸네일** 버튼을 누르면 썸네일 탭에서 마지막으로 저장한 이미지를 불러옵니다.
- 규격(피드/정사각/스토리/페이스북)을 바꾸면 배치가 자동으로 맞춰집니다.
- 템플릿마다 문구가 따로 저장됩니다.
- **게시글 문구 복사** 버튼으로 해시태그가 포함된 본문을 복사해서 바로 붙여넣을 수 있습니다.

## 폴더 구조

```
├─ server.js              # 서버 (정적 파일 제공 + 이미지 저장 API)
├─ public/
│  ├─ index.html          # 유튜브 썸네일 편집기
│  ├─ poster.html         # 학과 포스터 편집기
│  ├─ editor.js/.css      # 자유 편집 엔진 (자유 편집·엠블럼 탭이 함께 씀)
│  ├─ editor.html         # 자유 편집 (포스터) ─ 설정: editor-poster.js
│  ├─ emblem.html         # 엠블럼 편집 ─ 설정: editor-emblem.js
│  ├─ social.html         # 인스타·페이스북 편집기
│  ├─ app.css             # 공통 스타일
│  ├─ common.js           # 공통 저장 로직, 포스터 로고·엠블럼 심볼 추출
│  ├─ fonts/              # Pretendard 폰트 (저장 이미지에 폰트를 넣기 위해 로컬 보관)
│  └─ vendor/             # html-to-image (포스터를 이미지로 변환)
├─ baseImage/             # 기존 썸네일 원본
├─ basePoster/            # 학과 전단지 원본 (로고 추출에 사용)
├─ baseEmblem/            # 학과 엠블럼 원본 (심볼 추출, 이미지 목록에 표시)
├─ uploads/               # 자유 편집에 올린 이미지 (git 제외)
├─ projects/              # 자유 편집·엠블럼 작업 파일 (git 제외)
└─ output/                # 저장된 결과물
   ├─ thumbnail/
   ├─ poster/
   ├─ emblem/
   └─ social/
```

## 서버 API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| POST | `/api/save` | `{ dataUrl, name, kind }`를 받아 `output/<kind>/`에 저장합니다. `kind`는 `thumbnail`, `poster`, `social`, `emblem` 중 하나입니다. |
| GET | `/api/latest?kind=thumbnail` | 해당 폴더에서 가장 최근에 저장한 이미지 주소를 돌려줍니다. |
| GET | `/api/base-poster` | `basePoster/` 폴더의 첫 번째 이미지를 돌려줍니다. 로고 추출에 씁니다. |
| POST | `/api/upload` | `{ dataUrl }` 이미지를 `uploads/`에 저장하고 `{ url }`을 돌려줍니다. |
| GET | `/api/images` | `uploads/`와 `baseEmblem/`의 이미지 목록을 돌려줍니다. |
| GET/POST | `/api/project?name=poster` | 자유 편집 작업 파일(`projects/<name>.json`)을 읽고 씁니다. 엠블럼은 `emblem-square`, `emblem-circle`, `emblem-wide`입니다. |

## 참고

- 썸네일 탭의 폰트(Black Han Sans, Noto Sans KR)는 Google Fonts에서 불러옵니다. 인터넷이 없으면 기본 폰트로 표시됩니다. 포스터와 SNS 탭은 로컬 폰트를 써서 오프라인에서도 동작합니다.
- 브라우저에 자동 저장된 내용은 그 브라우저에만 남습니다. 다른 PC나 다른 브라우저에서는 기본 문구로 시작합니다.
- 전단지를 새 버전으로 바꾸려면 `basePoster/` 폴더의 이미지를 교체하면 됩니다. 로고는 원본 기준 좌표 `(128, 88, 576×152)`에서 잘라내므로, 레이아웃이 달라지면 `public/common.js`의 `posterLogo()` 좌표를 고쳐야 합니다.
