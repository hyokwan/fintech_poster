# Creator Studio

학교·학과 홍보물(포스터, 배너, SNS 이미지, 썸네일, 엠블럼)을 학과 로고와 색에 맞춰 만들고, 이미지 한 장으로 네이버 카페 글을 AI가 써서 바로 올려 주는 도구입니다.
서버 한 대를 띄우면 여러 학교·학과 사람들이 가입해서 함께 씁니다.

| 메뉴 | 용도 | 저장 규격 |
| --- | --- | --- |
| 홈 | 만들기 바로가기, 학과의 최근 결과물 (받기·지우기) | |
| 썸네일 | 유튜브 영상 썸네일 | 1280×720 PNG (2MB 넘으면 자동 JPG) |
| 포스터 | 모집 전단지를 글씨만 바꿔서 (빠른 편집) | 인쇄용 2480×3508 PNG / 웹용 1240×1754 JPG |
| 자유 편집 | 포스터를 미리캔버스처럼 자유롭게 | 포스터와 같음 |
| 배너 | 유튜브 채널 배너, 가로·띠 배너, **원하는 크기 직접 입력** | PNG / JPG / 2배 PNG |
| SNS | 인스타 피드·정사각·스토리, 페이스북 | JPG |
| 엠블럼 | 정사각·원형·가로형 | 투명 PNG, 흰 배경 JPG |
| 카페 글쓰기 | 이미지 → AI 제목·본문 초안 → 다듬기 → 네이버 카페 게시 | |
| 학과 설정 | 학과 정보, 로고·심볼, 네이버 카페 연결, 멤버 | |
| 관리자 | 가입 승인, 학교·학과 만들기, 학과별 멤버, AI 엔진, 네이버 앱 설정 | |

## 설치와 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
cp .env.example .env     # 필요한 값만 채우기 (비워둬도 실행됨)
npm start                # 개발 중에는 npm run dev (파일 바꾸면 자동 재시작)
```

브라우저에서 http://localhost:3001 로 접속합니다.

- 다른 PC에서 접속하게 하려면 `.env`에 `HOST=0.0.0.0`을 넣습니다. (기본은 이 PC에서만 접속)
- 도메인/https 로 서비스한다면 `PUBLIC_URL=https://주소`, `COOKIE_SECURE=1`을 넣습니다.

### 처음 한 번

1. **맨 처음 회원가입한 계정이 최고 관리자**가 됩니다. 서버를 띄우고 바로 가입하세요.
2. 첫 학과(AI핀테크융합과)는 자동으로 만들어지고, 최고 관리자가 그 학과의 학과 관리자가 됩니다.
3. 예전 버전의 작업 파일(`projects/`, `uploads/`, `output/`)이 있으면 첫 학과로 자동으로 옮겨집니다.

## 계정과 권한

- 회원가입하면 **승인 대기** 상태가 됩니다. 최고 관리자가 **관리자 › 가입 승인**에서 학과와 역할을 정해 승인하거나, 학과 관리자가 **학과 설정 › 멤버**에서 이메일로 추가하면 바로 쓸 수 있습니다.
- 한 사람이 여러 학과에 속할 수 있고, 위쪽에서 학과를 바꿉니다.

| 역할 | 할 수 있는 일 |
| --- | --- |
| 최고 관리자 | 모든 학과, 가입 승인, 학교·학과 만들기, AI 엔진·네이버 앱 설정 |
| 학과 관리자 | 학과 정보·로고·카페 연결·멤버 관리 + 편집자 권한 |
| 편집자 | 모든 편집기(작업 파일 저장), 카페 글쓰기 |
| 보기·저장 | 템플릿을 열어 이미지로 저장만 (작업 파일은 바뀌지 않음) |

## 다른 학교·학과에서 쓰기

관리자 › 학교·학과에서 학과를 만들고, 그 학과의 학과 관리자가 **학과 설정**에서 아래를 정하면 모든 템플릿에 자동으로 들어갑니다.

- 학교·캠퍼스·학과 이름, 영문 이름, 유튜브 채널 이름, 홈페이지, 한 줄 소개, 해시태그
- **학과 로고** (포스터·SNS 위쪽), **심볼 마크** (엠블럼·배너, JPG면 흰 배경 자동 제거), **자료 이미지** (편집기 이미지 탭)

템플릿 기본 문구 속 "한국폴리텍대학 / 서울강서캠퍼스 / AI핀테크융합과 / www.hkcode.co.kr"는 그 학과 값으로 바뀌어 보입니다. 과정 소개·일정 같은 내용은 학과마다 직접 고쳐 쓰세요.

## 네이버 카페 글쓰기

[네이버 카페 글쓰기 API](https://developers.naver.com/docs/login/cafe-api/cafe-api.md) 를 씁니다.

1. **최고 관리자** — [네이버 개발자센터](https://developers.naver.com/apps/#/register)에서 앱을 하나 등록합니다.
   - 사용 API: **네이버 로그인**, **카페** (API 권한관리에서 카페 체크)
   - 서비스 환경: PC 웹, Callback URL: `http(s)://서버주소/api/naver/callback` (학과 설정 › 네이버 카페에 정확한 주소가 나옵니다)
   - 앱이 '개발 중'이면 앱 멤버로 등록한 네이버 계정만 연결됩니다. 여러 학과가 쓰려면 검수를 받으세요.
   - 관리자 › 시스템 설정에 Client ID / Secret 입력
2. **학과 관리자** — 학과 설정 › 네이버 카페에서
   - **네이버로 연결** (카페에 글을 쓸 계정으로 로그인)
   - 카페 ID(`clubid`)와 게시판 이름·메뉴 ID(`menuid`) 입력
3. **편집자** — 카페 글쓰기에서 이미지를 올리고(또는 "내가 만든 결과물에서 고르기") **✨ 이미지 보고 글 쓰기** → 확인 후 **카페에 올리기**

카페 이름만으로는 글을 쓸 수 없습니다. 네이버 정책상 ① 등록된 앱, ② 그 카페에 글쓰기 권한이 있는 계정의 로그인 동의, ③ 카페 ID·게시판 ID 세 가지가 모두 필요합니다.

### AI 엔진 (카페 글 초안)

**관리자 › AI 엔진**에서 등록합니다. OpenAI 호환 API(`/v1/chat/completions`)면 무엇이든 됩니다.

| 예 | 주소 | 모델 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` (+ API 키) | `gpt-4.1-mini` 등 |
| Ollama | `http://localhost:11434/v1` | `gemma4:e2b` 등 |
| vLLM | `http://localhost:8888/v1` | `/v1/models` 의 id |

- **모델 불러오기**로 연결을 확인하고 모델을 고르고, 저장한 뒤 **시험**을 누르면 짧은 답이 옵니다.
- **글 쓰는 AI**와 **이미지 글자 읽기(OCR) AI**를 따로 정할 수 있습니다. OCR을 고르면 화면에서 긴 이미지(포스터 등)를 가로 띠로 잘라 글자를 먼저 읽고, 그 글자를 글 쓰는 AI에 넘겨 날짜·숫자를 더 정확히 옮깁니다. 기본값은 관리자가 정하고, 카페 글쓰기 화면에서 그때그때 바꿀 수 있습니다.
- 이미지를 못 읽는 모델은 "이미지를 읽을 수 있음"을 끄고 OCR 엔진과 함께 쓰세요. JSON 모드를 모르는 서버는 자동으로 일반 모드로 다시 요청합니다.
- AI가 쓴 날짜·숫자는 틀릴 수 있습니다. 올리기 전에 꼭 확인하세요. (작은 모델일수록 확인이 더 필요합니다)

## 사용법 안내

모든 메뉴의 위쪽 **❓ 사용법** 버튼을 누르면 그 메뉴의 매뉴얼이 팝업으로 나옵니다. 메뉴에 처음 들어가면 한 번 자동으로 보여줍니다. 내용은 `public/js/help.js`에서 고칩니다.

## DB

- 기본은 `data/studio.db` (SQLite, 설치할 것 없음)
- MariaDB/MySQL을 쓰려면 `.env`에 `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`을 넣습니다. 테이블은 처음 실행할 때 자동으로 만들어집니다.
- 다른 프로젝트와 겹치지 않게 테이블 이름은 모두 `hkpromo_`로 시작합니다: `hkpromo_users`, `hkpromo_orgs`, `hkpromo_members`, `hkpromo_projects`, `hkpromo_sessions`, `hkpromo_settings`
- 이미지 파일(업로드, 결과물, 학과 로고)은 DB가 아니라 `data/orgs/<학과 id>/`에 저장됩니다. 서버를 옮길 때 `data/` 폴더를 함께 옮기세요.

```
│  ├─ store.js            # 사용자·학과·멤버·작업 파일·세션·설정 (SQL은 여기만)

│  └─ routes/
│     ├─ auth.js          # 가입·로그인·내 정보(/api/me.js)·학과 전환
│     ├─ files.js         # 결과물 저장, 업로드, 작업 파일, 학과 자료 이미지

│     ├─ admin.js         # 최고 관리자

├─ public/
│  ├─ *.html              # 화면 (홈, 썸네일, 포스터, 자유 편집, 배너, SNS, 엠블럼, 카페, 설정, 관리자, 로그인)

│  │  ├─ editor.js        # 자유 편집 엔진 (자유 편집·엠블럼·배너가 함께 씀)
│  │  ├─ editor-poster.js / editor-emblem.js / editor-banner.js   # 각 편집기의 규격·기본 배치·도구
│  │  ├─ cafe.js          # 카페 글쓰기
│  │  └─ help.js          # 메뉴별 사용법 팝업 내용
│  ├─ images/             # 기본 학과 원본 (emblem/, poster/, thumbnail/)
│  ├─ fonts/  vendor/
└─ data/                  # (git 제외) DB, 학과별 업로드·결과물·로고
```

## 참고

- 편집기 사용법(끌어서 옮기기, 단축키 등)은 각 편집기 오른쪽 **사용법**에 있습니다.
- 썸네일·포스터·SNS 탭의 입력 내용은 브라우저에 학과별로 저장됩니다. 자유 편집·엠블럼·배너 작업은 서버에 저장되어 같은 학과 사람과 공유됩니다.
- 기본 학과의 로고는 원본 전단지(`public/images/poster/`)의 좌표 `(128, 88, 576×152)`에서 잘라 씁니다. 학과 설정에서 로고를 올리면 그 로고를 씁니다.
